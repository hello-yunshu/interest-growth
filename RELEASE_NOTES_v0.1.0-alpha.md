# v0.1.0 Personal Alpha

First usable release of Psychology Growth: an interest-first, evidence-aware psychology learning and expression workspace.

Highlights: curiosity capture/Quick Explore/pause/return/direct close, DeepTutor/DeepSeek/manual research fallback, human-reviewed Source/Evidence/Claim ledger with version history and auditable Skeptic Pass, flexible mastery, G1/G2/G3 Growth Memory + narrative/reflection, per-Claim Publish Guard, optional bounded DeepSeek prose enhancement, human-gated XHS/media prompt packs and local SVG information cards, and a deploy-driven first-party plugin lifecycle with safe update/rollback semantics.

DeepTutor is optional and pinned to stable v1.5.4 when enabled. No auto diagnosis, treatment decision or social publishing exists.
