# Image Prompt

For each page output purpose, composition, subject, style, palette, text-safe-zone, forbidden elements, and aspect ratio.

Reduce cognitive load and leave editorial breathing room. Do not fabricate screenshots, certificates, measurements, source documents, or visual evidence that was not supplied. Clearly separate visual metaphor from factual evidence.
