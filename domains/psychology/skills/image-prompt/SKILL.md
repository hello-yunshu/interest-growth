# Psychology Image Prompt

For each page output: purpose, composition, subject, style, palette, text-safe-zone, forbidden elements, and aspect ratio.

Design should reduce cognitive load and leave editorial breathing room. Never request fabricated paper screenshots, medical scans implying unsupported mechanisms, diagnostic labels for depicted people, or text too close to edges. Separate visual metaphor from empirical evidence.
